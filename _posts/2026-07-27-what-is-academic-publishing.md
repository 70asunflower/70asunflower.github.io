## 学术发表是什么：写给研究生的机制说明

研究生阶段会碰到一堆词：SCI、一区、影响因子、letter、CCF-A、大修、开源获取。单独查每个词都能查到意思，但查完一圈你依旧不知道它们之间是什么关系，也不知道谁定的。

这份文档要回答三件事：这套制度为什么长成这样；它有哪些部件，分别由谁说了算；你一个刚入行的人具体该做什么。弄清机制之后，那些名词不用背也能自己站好位置。

具体数字（影响因子、分区、录用率、费用）会随年份变化。本文讨论相对稳定的机制；涉及具体载体时，请以官方渠道和所在单位的当年文件为准。

> 本版核查时间：2026 年 7 月。

---

## 第一部分：这套制度到底在解决什么问题

### 1. 三个真实存在的需求

学术发表不是为了让人升职才发明的。它同时在干三件不相干的事，而很多奇怪的规则都是这三件事互相拉扯的结果。

**第一，分配注意力。** 全世界每年产出上百万篇论文，任何人一年能认真读完的不过几十篇。发表制度得把内容分堆、排序、打标签，让人能在不读的前提下判断该不该读。期刊、会议、分区、影响因子，本质上都是注意力的分发装置。

**第二，筛掉靠不住的结论。** 你无法亲自重复每一个实验，又需要在别人的结论上接着建。同行评审就是那个代理检查员：帮你看一眼方法有没有明显漏洞。它的上限很低（审稿人不重跑你的实验），但比没有强。

**第三，给贡献记账。** 知识一旦公开就不能独占，但发现它的人需要回报。发表系统用公开时间戳换取一个可验证的优先权记录，作者名字排序、引用、h 指数都是这本账的具体存取方式。

这三件事并不天然一致。“快点占住优先权”与“先把它审严一点”直接矛盾；预印本与 letter 就是为了在这个矛盾里找平衡才存在的。

### 2. 三层规则，谁定的很重要

新人最常见的困惑是把完全不同性质的规则摆到一起讨论。它们属于三层，定规则的人、变化速度、违反代价都不一样。

||学术共同体规范|出版产业规则|行政认定规则|
| --------| ------------------------------------| ----------------------------------------| --------------------------------|
|谁定的|全球同行，一百多年演化而成|出版商、数据库公司|你的学校、学院、基金委、人事处|
|典型内容|作者资格、引用义务、不得伪造、优先权|版面费、版权归属、索引收录、开放获取模式|毕业要几篇、认不认会议、奖金多少|
|变化速度|极慢|中等，商业利益驱动|快，可能一年一变|
|适用范围|全球通行|逐刊、逐出版商不同|仅你所在单位，跳十公里就变|
|违反后果|撤稿、学术声誉尽毁|稿件退回、无法发表|不能毕业、不算工作量|

三条推论，都很实用：

第一，“发一篇一区”这类目标属于第三层。第三层的规则必须去你本校本年的文件里查，网上的经验贴一律无效。师兄师姐两年前的经验也可能已经过期。

第二，第一层与第三层会相互抵触。行政认定可能诱导人把一项工作拆成多篇发表，共同体规范叫这个行为“切香肠”。两边都得照，但优先级很清楚：第一层的后果不可逆。

第三，第二层既不代表学术水平也不代表道德。交 APC 不丢人，只是一种商业模式；影响因子高也只是一个数据库公司的统计口径。

### 3. 同行评审具体怎么跑

这是整套制度里唯一的质量关口，也是最容易被误解的部分。

```
主编（Editor-in-Chief）
  看方向、定基调，一般不碰具体稿件
  ↓ 分配
副编 / 领域编辑（Associate Editor / Handling Editor）
  真正参与具体决策的人
  决定送不送外审、请谁审、意见矛盾时听谁
  ↓ 邀请
审稿人（Reviewer / Referee）
  二到四位，写意见并给出推荐等级
  无报酬，匿名，可以拒绝邀请
```

多数审稿工作没有额外报酬，而且是在科研、教学和项目工作之外完成的。审稿人能分配给单篇稿件的注意力有限。由此可以推出一组很实际的写作要求：

|因为|所以|
| ----------------| ----------------------------------|
|时间很短|摘要、引言末段、结论必须能单独看懂|
|优先看图|图要能脱离正文读，图注写完整|
|不会重跑实验|方法描述详细到可信，比写得好看重要|
|不会猜你想说什么|贡献列成三到四条，写在引言末尾|
|不熟悉你的子方向|术语、缩写、符号首次出现必定义|
|反感“不严谨”|不确定的结论主动限定范围，别夸|
|只能看到稿件|你心里知道但没写的事等于不存在|

#### 三种评审模式

- **单盲**（single-blind）：审稿人知道你是谁，你不知道它是谁。大多数期刊如此。名气与单位会有影响，这是客观存在的。
- **双盲**（double-blind）：互不知情。计算机会议普遍采用。需要你主动匿名化稿件、致谢和代码链接。
- **开放评审**（open review）：意见与作者回应公开，部分还会公开审稿人姓名。对新人有个巨大好处：可以直接去读同行的审稿意见，看真实的审稿标准长什么样。

#### 审稿意见的方差很大，这是常态

同一篇稿子，一位审稿人说“建议接受”、另一位说“建议拒稿”，十分常见。原因并不神秘：审稿人的知识背景、对“多少增量算够”的阈值、当周心情都不一样。一次拒稿只反映特定评审人在特定流程中的判断，不能证明你的工作没价值。更值得重视的是多位审稿人独立提出的同一个问题：这通常说明稿件确实存在表达或设计上的共性障碍。

## 第二部分：发表载体的完整谱系

### 4. 先看一张坐标

所有载体只需两个维度就能安置：成果的成熟度，以及从投出去到公开的速度。

```
快
↑  预印本                会议摘要 / poster
│  （无审稿，当天公开）    （轻审，两三个月）
│
│          Letter / Communication
│          （完整审稿，篇幅短，一到三个月）
│
│  会议正文                期刊正刊论文
│  （严审，三到六个月）      （严审，可多轮，六个月到两年）
│
│                          综述 / 专著章节
慢 ↓                        （需已有声誉，周期极长）
   低 ←────── 成果成熟度 ──────→ 高
```

四个常见误解先清掉：

 **“Letter 比期刊低一等”——不对。** Letter 是一种文稿类型，不是一种刊物类型。它可以出现在任何档次的刊上，包括那些最顶的。它限制的是篇幅与叙事完整度，不是审稿严格度。

 **“会议论文比期刊论文低”——分领域。** 在体系结构、操作系统、机器学习这些方向，顶会是重要工作的首发渠道，地位高于大多数期刊。在材料、化学、医学方向，会议基本只是交流场合。这不是“习惯差异”，而是由领域的迭代速度决定的：一个年均变天的领域等不起两年的期刊周期。

 **“预印本不算成果”——分用途。** 它不能算行政工作量，但它在共同体层面确立了优先权，而且很多领域的人真的先从预印本看到你的工作。

 **“综述好写”——相反。** 综述引用高，但需要你对一个领域熟悉到能判断哪些工作重要。高档刊的综述多数是编辑邀稿，自由投稿很难中。新人写综述容易写成文献流水席。

### 5. 期刊里到底有哪些文稿类型

同一本刊会开好几个投稿通道，选错通道会直接退稿。这些名字各刊不完全统一，但内涵大体固定。

**Research Article / Regular Paper（正刊论文）** 
默认选项。完整叙事：问题、方法、实验、对比、分析、结论。篇幅典型八到十四页。审稿可能两三轮。你的主体工作基本都走这里。

**Letter / Communication / Rapid Communication**
通常用于篇幅较短、结论集中、希望较快传播的工作。常见限制是四到六页或固定字数，参考文献也可能受限。不过，这些名称没有跨期刊统一的定义：有的 Letter 强调快速传播，有的只是限制篇幅，有的仍要求相当完整的实验。是否更快、审稿几轮，都要看目标期刊的 Article Types 页面。同一内容后续扩展为正刊论文时，必须有可辨识的实质新增，并披露前序版本。

**Brief Paper / Short Paper / Technical Note**
与 letter 类似但定位略不同，往往用于已有方法的改进、工程实现细节、或一个漂亮但局部的技术点。

**Review / Survey / Tutorial**
综述、系统调研、教程。篇幅长，引用高，多数需先发信问编辑（叫 pre-submission inquiry）。Tutorial 偏教学，Survey 偏梳理与分类，一份好的 survey 必须有自己的分类体系与批判性判断，不能只是按时间顺序罗列论文。

**Perspective / Viewpoint / Position Paper**
观点文章。不靠新实验，靠对领域趋势的判断。不适合新人，但值得读——它们往往直接告诉你一个领域现在的真问题在哪里。

**Comment / Reply**
对已发表论文的公开质疑，以及原作者的回应。两者通常同期发表。这是学术争论的正式渠道。

**Corrigendum / Erratum / Retraction**
更正与撤稿公告。Corrigendum 是作者自己的错，Erratum 一般指出版方的错，Retraction 是文章被撤回。它们也是正式发表内容，永久留在记录里。

**Special Issue （专刊）** 
围绕一个主题组稿，有客席编辑与固定截止日。优点是方向匹配度高、周期往往更可控；需注意两件事：一是部分单位对专刊论文评价略低，二是正规专刊与借专刊名义群发的可疑征稿要分清。官网公告只是第一步，还要核对客座编辑、出版商页面、审稿政策和费用说明。

### 6. 会议里的类型

**Full Paper（正文）** ：完整工作，固定页限，一次定生死，最多一轮书面回应机会。

**Short Paper**：篇幅减半，单点结果。部分会议会把“不够录正文但有价值”的稿子降为这一类。

**Poster**：一页到两页摘要，现场贴图并站在旁边讲。对新人的真实价值在于：两小时里你能与几十个同行一对一讲自己的工作，这种密度的反馈很难从其他地方获得。

**Workshop**：与正会并行的小型会场，审稿宽、规模小、讨论多。正确用法是提早暴露未成熟的工作换取反馈。多数会议允许 workshop 版后续投正会，但需逐会确认。

**Demo / Late-breaking Results / Extended Abstract**：演示、新鲜结果、扩展摘要。周期短，往往不计入正式成果统计，但不影响后续正式发表。

**Invited Talk / Keynote**：邀请报告，不经审稿，看声誉。

一个需要提前知道的事：不少会议要求至少一位作者注册并完成现场或线上报告，违反 no-show policy 可能影响论文集收录。注册费、差旅费、签证时间要在投稿前就弄清楚能不能报。

### 7. 预印本

未经同行评审就公开的稿件，平台如 arXiv、bioRxiv、SSRN。上传当天就有永久链接与时间戳。

它能干什么：占住优先权；让同行提早看到；找工作时有东西可以拿出手；收到非正式反馈。

它不能干什么：不算行政成果；不等于经过验证。

三个实际注意点。一是大多数期刊不把预印本算重复发表，但少数刊仍介意，投前查一下它的 preprint policy。二是部分双盲会议对提交窗口期内新发预印本有限制，上传前先查当年规则，这个错事后补不回来。三是上了预印本就是公开的，不要上自己两个月后会后悔的版本。

### 8. 其他也算发表的东西

**专著章节（book chapter）** ：常用于成熟主题的系统介绍或受邀合集。审稿与认定差异很大，投入前应先确认它对当前研究目标是否有实际价值。

**学位论文**：公开后可以被检索和引用，也能提供公开时间戳。多数期刊允许学位论文中的内容改写后投稿，但仍应引用原学位论文、披露重合关系，并核对目标期刊政策。

**专利**：与论文是两套制度。论文、预印本、报告或代码公开都可能影响专利新颖性。只要存在申请专利的可能，就应在任何公开披露前联系本单位知识产权部门或专利代理人，不要依赖事后的宽限期补救。

**技术报告、白皮书、开源项目**：不在传统认定体系内，但在工业界与部分系统社区真实有分量。求职时它们的作用可能比一篇普通期刊文大。

### 9. 同一份工作可以有多个发布形态

一个典型的完整链条：预印本 → workshop 短文 → 会议正文 → 期刊扩展版。这不是重复发表，因为每一步都有实质新增。但边界很硬：

|情形|允许吗|条件|
| ----------------| --------| ----------------------------------------------------------------------------------|
|先发预印本再投刊|通常可|查目标刊的 preprint policy|
|会议文扩成期刊文|通常可|有可辨识的实质新增，引用会议版，并在 Cover Letter 说明差异；具体以目标期刊政策为准|
|同时投两本期刊|禁止|一稿多投，后果严重|
|中英文各发一篇|基本禁止|除非两刊均书面同意并声明|
|数据拆成多篇|看情况|每篇有独立的完整贡献才行|
|被拒后改投|当然可|上一家已正式退稿后才能投|

切香肠与正当拆分的区分，有一个简单自检方法：把两篇的贡献陈述写下来，如果它们能互换而不影响含义，它本来就应该是一篇。

### 10. 开放获取：钱从哪来

传统模式是订阅制：读者（实际上是学校图书馆）付钱，作者不付或只付少量版面费。开放获取把这个关系反转了：

- **金色**（gold）：全刊开放，作者付 APC。典型一千五到四千美元，高影响力刊可超六千。
- **混合**（hybrid）：订阅刊提供可选的付费开放。不付也能发，只是非订阅者看不到。
- **绿色**（green）：在机构库或预印本平台自存档，不花钱。多数刊允许存接收稿版本，有时有禁制期。
- **钻石**（diamond）：两边都不收费，靠学会或机构补贴。数量少但存在。

**掠夺性期刊**就是这个商业模式的可预期产物。既然作者付钱且付钱发生在录用之后，那么“什么都录”就是一个盈利策略。它们的典型特征：主动群发邮件约稿、承诺一两周录用、官网编辑部信息模糊、影响因子叫一些你没听过的名字（如“Global Impact Factor”）、收费前不说清。

验证途径按可靠度排：Clarivate Master Journal List（mjl.clarivate.com）查是否真被 SCIE 收录；DOAJ 查开放获取刊是否合规；中国科学院国际期刊预警名单逐年发布，入列的平时不要碰。早年流传的 Beall's List 原作者 2017 年已停止维护，现存的都是匿名镜像，只能当辅助参考。

## 第三部分：那些数字到底衡量了什么

### 11. 影响因子的精确定义，以及它为何不能当单篇评价

某刊 2025 年的影响因子：

```
        2023 与 2024 年发表的论文，在 2025 年被引的总次数
IF = ────────────────────────────────────────
            2023 与 2024 年发表的可引论文数
```

就是这么一个两年期的均值。由 Clarivate 公司每年六月左右发布。三个结构性问题：

**均值被长尾拉得很厉害。** 一本刊里往往不到一成的文章贡献了大半引用。一篇 IF=10 的刊上的论文，中位数引用可能只有三四次。所以 IF 说的是这本刊，不是你的文章。

**综述能把它拉高很多。** 综述天然高引，多发综述就能抬 IF。一些刊的 IF 暴涨就是这么来的。

**跨领域直接比较意义有限。** 医学与生物引用活跃度比数学与工程高一个数量级。计算机顶刊 IF 很少超过二十，而医学顶刊轻松上百。这不说明任何水平差异。

其他常见指标：

- **h 指数**：有 h 篇论文各被引至少 h 次。评人不评刊。优点是不容易被单篇爆款主导，缺点是对年轻人天生不利（需要时间积累）。
- **CiteScore**：Scopus 的对应指标，统计窗口四年，分母口径更宽，数值与 IF 不可直接比。
- **JCI**（Journal Citation Indicator）：Clarivate 做的学科归一化指标，1.0 为平均水平。设计目的就是让跳领域比较变得有意义。
- **期刊超越指数**：中国科学院分区从 2022 年升级版起采用的指标，重点看论文质量分布而非均值。
- **分位**（percentile）：比绝对值有用得多。“本领域前 10%”比“IF=6.2”信息量大。

### 12. 两套分区，完全不同的东西

中国学生口中的“一区”可能指两个不同的体系，而它们结论差很多。

||JCR 分区|中国科学院分区|
| --------| -----------------| -----------------------------|
|发布方|Clarivate（美国）|中科院文献情报中心|
|一区占比|各学科前 25%|大致前 5%|
|依据|影响因子排序|期刊超越指数（2022 升级版起）|
|学科划分|约两百多个小类|大类与小类两套，可差一档|
|国际认知|高|国内为主|
|国内认定|部分单位用|大多数单位用这个|

三个实际使用中的坑。

一、中科院一区与 JCR 一区差很远。前 5% 与前 25% 不是同一个难度。很多人看到一本刊“是一区”就开心，结果本校用的是另一套。

二、大类与小类可以差一档。同一本刊可能小类二区、大类三区。本校文件里写的是哪一套，必须确认。这影响能不能毕业。

三、分区表年份会漂。分区每年变，且发布时间不固定。你投稿时它是二区，发表时可能掉到三区。一般以发表当年或当年度最新表为准，但以哪一版为准由你单位说了算。这是另一个必须提前问的问题。

### 13. 索引、分区、分级：不要混成一条排名

这几类工具回答的是不同问题：

|名称|类型|主要回答什么|
| -----------------------| --------------------| --------------------------------------------|
|SCI / SCIE、SSCI、A&HCI|引文索引|该刊是否进入 Clarivate 的相应数据库|
|EI Compendex|工程文献索引|该文献是否进入工程技术文献库，兼收期刊与会议|
|Scopus|综合文摘与引文数据库|文献是否被其更广泛的来源体系覆盖|
|CPCI|会议论文索引|会议论文是否进入 Web of Science 的会议录|
|JCR 分区|期刊分区|期刊在其 JCR 学科中的相对位置|
|中科院分区|期刊评价工具|期刊在国内常用评价口径中的相对位置|
|CCF 推荐目录|专业学会推荐目录|计算机领域内具体会议与期刊的社区评价|

因此，“被 SCI 收录”只说明期刊在相应索引中，不能直接替代质量判断。SCI 与 EI 的覆盖对象和收录目的不同，也不存在普遍有效的高低换算。

在国内部分单位的行政认定中，SCIE 期刊往往比普通 EI 来源获得更高权重；但计算机领域不能只看索引标签。许多重要成果首先发表在高水平会议上，实际分量需要结合具体会议、社区共识和本单位文件判断。

同理，“CCF-B 相当于中科院几区”没有通用答案。CCF 目录本身是专业学会评价；学校如何使用它，才属于行政认定。

### 14. 认定制度正在变，以及错了怎么办

“破五唯”要求不单以论文、职称、学历、奖项、帽子作为评价依据，很多单位因此改为代表作制：不数篇数，而是看你选出的一到三篇。对你的实际影响：一篇真正想清楚的工作，价值高于三篇凑数。但注意，毕业硬指标往往没变，两个体系同时运行。

发表后发现问题，有正式渠道处理，四个级别：

- **Corrigendum / Erratum**：更正局部错误，结论仍成立。主动发更正不丢人，反而是负责的做法。
- **Expression of Concern**：编辑部公开表示存疑，调查中。
- **Retraction**：撤稿。文章仍可检索，但标上撤稿标记。
- **Removal**：极少见，一般涉及法律或隐私问题。

Retraction Watch 长期跟踪撤稿事例。花半小时翻一下很有用：你会发现大多数撤稿不是因为伪造数据，而是因为图片重用、统计错误、未披露利益冲突这些看起来“不致命”的事。

## 第四部分：一篇稿件怎样变成正式记录

### 15. 六个阶段

一篇期刊稿件通常会经过：形式检查 → 编辑初筛 → 外部评审 → 作者修改 → 编辑决定 → 出版与入库。

编辑初筛解决的是“是否适合送审”，不是完整评价论文质量。外部评审通常由两到四位同行完成；意见可能一致，也可能相互矛盾。作者收到修改机会后，需要同时提交修改稿和逐条回应信。编辑综合原稿、审稿意见和作者回应，作出接受、继续修改或拒稿的决定。

投稿系统中的 With Editor、Under Review、Major Revision 等状态只是流程标签，不同出版商的命名和切换逻辑并不完全一致。具体状态、合理等待时间以及如何写回应信，放在下一篇《选刊与选会》中详细讨论。

### 16. 接受不等于流程结束

录用后通常还有几步：

1. **版权或许可协议**：确定版权授权和开放获取方式。
2. **校样**（proof）：核对排版、公式、图表、作者信息和明显笔误；通常不能借机重写内容。
3. **Early Access / Online First**：已有 DOI、可以引用，但可能尚未分配卷期页码。
4. **正式编入卷期**：获得完整的卷、期、页码或文章号。
5. **数据库入库**：进入 Web of Science、EI 或其他数据库，时间可能继续滞后。

所在单位究竟认录用函、在线发表、正式卷期还是数据库检索，属于行政认定问题，必须查看本单位当年文件。倒排毕业、评奖或求职时间时，应把录用后的滞后也算进去。

## 第五部分：署名就是责任

### 17. 作者名单不是人情列表

不同学科的作者资格标准并不完全一致。医学与生命科学中广泛采用的 ICMJE 标准要求同时满足以下四项；其他领域虽然表述不同，也普遍强调实质贡献、参与写作、认可最终版本和承担责任：

1. 对研究构想、设计、数据获取或分析有实质贡献
2. 参与了论文的起草或实质修订
3. 认可最终版本
4. 愿意对工作的完整性负责

第四条是很多人从没想过的。署名不是只有好处：如果论文将来因数据问题被质疑，所有作者都要接受代价。“帮忙提供了一下设备”、“一直没参与但是导师的导师”这类情况，按规范应归入致谢而非作者。现实中不一定能按规范执行，但你得知道规范是什么。

### 18. 作者位置各自意味着什么

|位置|含义|学生阶段的常见归属|
| --------| --------------------------| --------------------------------|
|第一作者|主要工作执行人|你自己的工作应该归你|
|共同一作|两人贡献相当，用星号标注|部分单位不认或只认排在前面的那位|
|中间作者|参与具体环节|分量低，但不是零|
|通讯作者|对外负责，学术负责人|通常是导师|
|末位作者|很多领域默认等于资深负责人|与通讯作者常为同一人|

**CRediT** 是一套标准化的贡献分类体系（概念提出、方法学、软件、验证、正式分析、调查、资源、数据管理、写作起草、审阅与编辑、可视化、监督、项目管理、经费获取）。越来越多刊物要求逐人填写。它的作用是描述贡献，而不是自动决定谁有资格署名；作者资格仍要按目标期刊和所在学科的规则判断。

### 19. 四件事必须在动手前说清

这四个问题很少有人主动提，而每一个事后都难转回：

1. **这份工作完成后，作者顺序预计怎么排。** 得到“到时候再说”也是一个信息。
2. **若中途换方向或毕业离开，未完成部分归谁。** 很多纠纷源于这里。
3. **数据、代码、硬件平台的使用与开源权限属于谁。** 涉企业合作或保密项目时尤其重要。
4. **若涉及联合培养、联合实验室或企业实习，署名单位怎么写、认定归哪边。** 这一条属于“很多人到投稿前一周才发现”的类型。

### 20. 学术不端的具体形态

除了大家都知道的伪造数据与抄袭，还有几类容易“无心踩线”的：

- **一稿多投**：同时投两家。就算只是想省时间，后果也很严重。
- **切香肠**：把一份工作拆成多篇凑数量。
- **重复发表**：会议扩展稿没声明出处、或扩充量不够。
- **图像不当处理**：为了好看而拉伸、拼接、删背景。这在实验学科是撤稿大头。
- **引用操纵**：为迎合审稿人而强塞无关引用，或导师要求大量自引。
- **代写代投**：不仅不端，很多情况下还违法。
- **AI 使用未披露**：目前主流立场是——可以用于语言打磨，不能作为作者署名，涉及内容生成需按刊物要求声明。各刊政策仍在变，投前查当前版本。

## 第六部分：你具体该怎么进去

### 21. 四个阶段，每个阶段有明确产出

**阶段一：把十篇论文读到能复述。** （一到两个月）
选本方向近三年最重要的十篇，怎么选？从一篇新综述的参考文献里找高频出现的。不是浏览，是读到能回答三个问题：它解决了什么问题；与上一篇相比多了什么；审稿人自己承认的局限是什么。
产出：一份自己的笔记，能画出这十篇的关系图。

**阶段二：完整复现一篇。** （一到两个月）
选一篇有开源代码的，把它的主结果跑出来。这一步的真正价值不是“学会它的方法”，而是你会亲身发现：论文里没写的细节比写了的多；很多数字重复不出来；官方代码与论文描述不一致。这些差距本身就是选题的来源。
产出：一份能重复执行的实验环境与脚本，以及一张差异清单。

**阶段三：做一个能说清的增量。** （三到六个月）
不需要“提出新框架”。升一个具体指标、在一个新场景下重新验证、指出一个普遍假设在新条件下失效，都是完整的贡献。关键是你能用三句话说清“之前不行，现在行，因为什么”。
产出：一个能写成 workshop 短文或 letter 的结果。

**阶段四：完整跑一遍流程。** （三到十二个月）
选刊、投稿、被拒、修改、再投。完整跑过一遍之后，这套制度就不再神秘了。很多人卡在这一步的原因是等“准备好”，而准备好这个状态不存在。

### 22. 真实成本

|环节|典型耗时|容易低估的部分|
| --------------| ------------| ------------------------------|
|读文献建立判断|一到三个月|不是读完，是读到能判断好坏|
|做实验|三到十二个月|失败的尝试占一半以上|
|写初稿|两到六周|图要重做好几遍|
|内部修改|两到四周|导师没时间看，要排队|
|选刊与投稿|一到两周|格式、推荐审稿人、Cover Letter|
|等审稿|两到六个月|不可控，也不应该空等|
|修改与回应|一到三个月|回应信本身很耗神|
|录用到见刊|一到三个月|很多人完全没算这一段|

一篇从零开始的期刊论文，从定题到真正能写进简历，一到两年是正常量级。提前知道这个数字，比事后发现要好。

### 23. 十条常见误解

1. “发不了顶刊就没价值”——绝大多数有用的工作发在中档刊与中档会。
2. “被拒一次说明工作不行”——一次拒稿只代表一个人在一个时间点的一个判断。
3. “影响因子高就是好刊”——要看领域与分位，且 IF 评的是刊不是你。
4. “交钱的刊都不正经”——开放获取是一种商业模式，很多顶刊也收。关键看审稿是不是真的。
5. “中文刊不算数”——部分中文刊国内认定很硬，看本校文件。
6. “会议论文比期刊低”——分领域，计算机顶会高于大多数期刊。
7. “EI 一定比 SCI 低”——CCF-A 会议多数只被 EI 收录。
8. “发表了就是定论”——发表只意味着通过了一道低阈值筛查。
9. “创新必须很大”——可靠的小增量比含糊的大叙事好得多。
10. “弄懂了再开始”——这套制度只能跑一遍才真懂。

## 附录 A：术语速查（标注它属于哪一层）

括号里标的层级对应第 2 节：共 = 学术共同体规范，产 = 出版产业规则，行 = 行政认定规则。

**载体与文稿类型**

- Article / Regular Paper（产）：完整的正刊论文
- Letter / Communication（产）：篇幅短、周期快的正式论文，审稿仍严
- Review / Survey / Tutorial（产）：综述类，多为约稿
- Special Issue（产）：专刊，有客席编辑与截止日
- Preprint（共）：未经评审就公开的稿件，确立优先权
- Proceedings（产）：会议论文集

**审稿与决定**

- Peer Review（共）：同行评审
- Single-blind / Double-blind / Open Review（共）：三种盲审模式
- Desk Reject（产）：未送外审即退稿，不携带质量信息
- Major / Minor Revision（产）：大修与小修
- Reject and Resubmit（产）：名为拒稿，实为邀请重投
- Transfer（产）：同出版商内转刊，审稿意见随行
- Rebuttal（产）：会议审稿后的一次短窗口书面回应
- Response Letter（产）：期刊修改阶段的逐条回应信
- Meta-review（产）：领域主席的总结意见，优先级高于单个审稿意见
- Camera-ready（产）：录用后的最终排版稿
- Artifact Evaluation（共）：可复现包审查

**指标与分级**

- SCI / SCIE / EI / Scopus / CPCI（产）：索引数据库，不是等级
- Impact Factor（产）：两年期引用均值
- JCR 分区（产）：按 IF 在学科内分四档，一区占 25%
- 中科院分区（行）：另一套体系，一区约占 5%
- CCF 推荐目录（行）：中国计算机学会的 A/B/C 分档
- h 指数 / CiteScore / JCI（产）：其他引用指标

**费用与开放**

- APC（产）：文章处理费，作者付
- 超页费（产）：超出免费页数后每页收费
- Gold / Hybrid / Green / Diamond OA（产）：四种开放获取模式
- Predatory Journal（共）：掠夺性期刊

**作者与诚信**

- Corresponding Author（共）：通讯作者，学术负责人
- CRediT（共）：标准化贡献分类
- Cover Letter（产）：投稿时给编辑的信
- Salami Slicing（共）：切香肠，不当拆分
- Corrigendum / Retraction（共）：更正与撤稿

## 本文的框架

```
三个需求：分配注意力 / 筛掉靠不住的结论 / 给贡献记账
     ↓
三层规则：共同体规范（慢、全球、后果不可逆）
           出版产业规则（商业驱动、逐刊不同）
           行政认定规则（快、本地、必须自己查）
     ↓
载体谱系：成熟度 × 速度两个维度就能摆完
度量体系：索引 ≠ 分区 ≠ 分级，三者不可换算
作者制度：署名意味着愿意对完整性负责
```

这套制度看上去繁琐，但它的每一条规则都派生于一个很普通的约束：同行的注意力是稀缺的。想不起某条规则为何存在时，从这一句往回推，基本都能推出来。
