## Why Jekyll?

Jekyll is a static site generator that transforms plain text into static websites and blogs. Combined with the [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) theme and GitHub Pages, you get a clean, fast, and free personal blog.

## Key Features

- **Markdown-based writing** — Focus on content, not formatting
- **GitHub Pages hosting** — Free, fast, and reliable
- **Categories & Tags** — Built-in taxonomy for organizing posts
- **Dark/Light mode** — Follows system preference with manual toggle
- **PWA support** — Installable as a mobile app

## Quick Start

```bash
# Install dependencies
bundle install

# Local development
bundle exec jekyll serve

# Build for production
bundle exec jekyll build
```
